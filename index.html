🐤 Chicken Keyboard

Chicken Keyboard is a personal Android keyboard with built-in AI translation. It helps its owner translate messages while typing in chat apps, using web AI services the owner is signed in to, a personal offline phrase pack, and an on-demand screen translation feature that only reads the screen when the owner taps its button.

The app is developed for personal use. It contains no ads and no analytics.
